# Input in Python

The `input()` function is used to take input from the user.

By default, the input received is stored as a **string**.

## Types of Input

### String Input

- Used to take text or character input from the user.
- No conversion is required because input is already a string.

### Integer Input

- Used when the user input needs to be treated as a whole number.
- Type casting is required to convert the input into an integer.

### Float Input

- Used when the user input needs to be treated as a decimal number.
- Type casting is required to convert the input into a float value.

## Key Points

- `input()` always returns a string value.
- Type casting is used to convert input into different data types.
- Common type conversions include string, integer, and float.
