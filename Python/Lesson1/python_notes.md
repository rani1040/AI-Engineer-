# Python Basics: Print Statement

## Print Statement

- `print()` is a built-in Python function used to display output on the screen.
- It can print text, numbers, and calculation results.

## Multiple Values

- Multiple values can be printed together using a comma (`,`).
- Python automatically adds a space between values.

## `end` Parameter

- By default, `print()` moves to the next line after execution.
- `end` is used to control the ending character and keep output on the same line.

## Escape Characters

- `\n` → New line
- `\t` → Tab space

## Key Points

- `print()` displays output.
- Comma prints multiple values.
- `end` controls line behavior.
- Escape characters format output.


# Python Variables and Data Types

## Variables

- Variables are used to store values in Python.
- A variable can store different types of data like numbers, text, or true/false values.

## Rules for Naming Variables

- Variable names can contain letters, numbers, and underscores (`_`).
- Variable names cannot start with a number.
- Spaces are not allowed in variable names.
- Special characters are not allowed except underscore (`_`).
- Python keywords cannot be used as variable names.
- Variable names are case-sensitive (`age` and `Age` are different).

## How Variables Work in Memory

- When you create a variable, Python creates an object in memory to store the value.
- The variable name acts as a reference that points to the memory location of that value.
- Multiple variables can point to the same value in memory.
- When a variable is assigned a new value, it points to a new object in memory.

- variable → points/references to a memory object, but Python hides the actual memory address.

## Integer (`int`)

- Used to store whole numbers.
- Does not contain decimal points.

## String (`str`)

- Used to store text values.
- Includes characters, words, and paragraphs.
