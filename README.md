# 📖 About This Repository

This repository is my personal **365-day journey** to becoming a professional AI Engineer.

Instead of learning random topics from different tutorials, I follow a structured roadmap that builds knowledge step by step—from Python fundamentals to building and deploying production-ready AI systems.

The goal is not just to learn AI, but to understand how modern AI systems are designed, built, deployed, and scaled.

By the end of this roadmap, I will be able to:
